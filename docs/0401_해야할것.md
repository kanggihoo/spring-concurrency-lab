## 순차 테스트 환경에서 2개의 환경 비교 분석하기(외부 시각화 도구 이용)

Prometheus에는 `query_range` API가 있어서 특정 시간 범위의 메트릭을 JSON으로 뽑을 수 있습니다:

```
GET /api/v1/query_range?query=reservation_success_count&start=...&end=...&step=5s
```

각 테스트 시작/종료 시간을 기록해두고 → 사후에 Prometheus에서 데이터 추출 → 경과 시간(t=0 기준)으로 정규화해서 seaborn으로 비교하면 **가장 정확한 비교**가 됩니다.
